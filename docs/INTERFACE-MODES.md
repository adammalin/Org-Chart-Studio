# Simple and Advanced workspaces

New sessions start in **Simple**. Use **Workspace mode** in the sidebar (bottom navigation on narrow screens) to switch. The choice is remembered on this device for the current browser origin or desktop installation. It is not included in chart exports or imported libraries.

## Simple

- Open a chart from the library; select a card to update its display name, role, assignment, status, or effective date.
- Expand **Organization structure & source details** for the full organization name, parent, source notes, uncertainty, and publishing settings. Collapsed fields keep their values when you save.
- Review AI updates through the persistent proposal banner and Before/After dialog. Pending AI imports have their own **Review imports** shortcut. Apply, Reject, and Review later work in either mode.
- Use **Review queue** for unresolved source questions. A mode change does not confirm records or designate a chart Current.
- Use **History / Timeline** for dated checkpoints. Individual edits and undo receipts, named-version comparisons, and AI decisions each have their own expandable section.
- Use **Monthly updates**, **Backup & restore**, and **Publish & export** from the sidebar. **Import chart** remains in the library, and **Table view** remains in the editor.
- For portable libraries, keep watching **Library file needs saving**. The primary Save action stays visible. **More file options** contains Save a copy, download fallback, optional encryption, the encrypted-file passphrase, and linked-file autosave when available. Browser recovery is distinct from saving a library file.

Simple protects saved card positions from accidental dragging. Pan, zoom, branch expansion, selection, editing, Undo, and Redo remain available.

## Advanced

Advanced uses the same data, review process, history, and file formats. It adds:

- **Appearance & layout**: official or annotated drawing, local chart fonts, compact/individual presentation, layout modes, connector routing, branch dragging, and area selection.
- **Advanced tools**: accessible table, source/intake tools, and cross-chart consistency checks.
- Card-position controls and contextual connector/selection tools.

These groups start collapsed to keep the chart visible. Source arrangement details and chart-control help are also expandable. Existing layout, appearance, routing, and pin preferences are preserved when you change modes.

Switching modes keeps the open chart and unfinished card fields intact. It does not save a chart, change reporting lines or source geometry, clear review questions, alter AI access, or grant approval. AI access can still be paused from AI control in either mode; detailed access settings and receipts are expandable.

## Guided tutorials

**Tips & tour** opens a chooser for two separate walkthroughs:

- **Simple — 12 topics:** library files and saving; search; library views, creation and import; basic card updates; undo and recovery; AI access and Before/After decisions; source reviews; lifecycle; historical checkpoints; monthly updates; backups and restore; audience-aware exports and the final library save.
- **Advanced — 18 topics:** all Simple topics, plus detailed hierarchy and assignments; card layout and pins; connector routes, source typography and arrangement; source-evidence import proposals; accessible tables; cross-chart consistency.

Use **Next topic**, **Back**, or **Jump to topic**. Arrow keys move between topics, Tab stays inside the tutorial, and Escape closes it. Each tour temporarily previews its interface mode and relevant workspace sections. Closing restores the previous section, mode and card selection, retaining unfinished card fields. A tour never applies a proposal, edits a chart, creates a checkpoint, changes AI permissions, or saves/exports a file.

The file and AI guidance follows the runtime: browser recovery and working-file saves on the web; the local database and separate portable file workspace on desktop. When the library is empty, chart-specific topics stay in the library and explain that a chart must be opened or imported first. Both tours can be replayed; completion is remembered separately on this device when preference storage is available.
