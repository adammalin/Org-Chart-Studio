# Automatic connector alignment

New browser sessions default to **Automatic alignment**. Compatible primary reporting relationships from the same parent and nearby child row share one level branch and a common stem where routing permits it. This is a drawing preference: it does not move cards, change identifiers, or edit reporting relationships.

**Align connectors** is available beside **Fit view** in both Simple and Advanced mode. It selects Automatic alignment for the current browser. The same routing choice feeds SVG, PNG, PDF and editable PowerPoint exports.

Existing explicit **Separate lanes** and **Sibling combs** preferences remain available under **Advanced → Appearance & layout → Connectors**, and are preserved on upgrade. Use Align connectors to return to automatic alignment. The preference applies to that browser's chart views and exports; it is not a chart-data edit or a promise of cloud synchronization.

Automatic alignment leaves a parent's port arrangement alone if any sibling connector is manually pinned or has a valid captured source route. It also keeps different relationship meanings and distant child rows separate. Existing compact presentations retain their established rail routing. Unrelated cards remain routing obstacles; the router can use a shorter initial stem to reach a clear side channel in a tight gap.

The companion can use the visible Align connectors control through supported browser UI. There is no new auto-layout MCP operation, and missing browser tools do not authorize hidden storage or database writes. Do not reset manually pinned/source-captured lines merely to make a diagram more symmetrical.

Geometry checks cover aligned and separate sibling branches, semantic separation, manual/captured preservation, obstacles and parity between canvas routing and the shared export scene. These checks do not certify source content, human approval or Current designation.
