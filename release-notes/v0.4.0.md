# OrgChart Studio 0.4.0 candidate

Browser-first candidate with a static GitHub Pages build, one shared editor and application command layer, browser SQLite transactions persisted through IndexedDB, and shared browser/desktop agent operations.

Working-library files preserve IDs, monthly work, source evidence, pending reviews and durable undo/redo. Open continues a working library; Merge backup retains copy semantics. Unencrypted files are the default; optional encryption also protects browser recovery and requires unlocking after reopening. User-selected synced folders use the computer's existing OneDrive/Dropbox client. Studio distinguishes verified file writes, prepared downloads and user-confirmed downloads.

Browser tools include the existing 30 shared operations plus metadata-only workspace status and save handoff. Availability depends on the browser/agent host. Desktop-only settings are hidden in browser mode. Desktop can open a separate portable-file workspace without replacing its original database or redirecting its stdio MCP connection. New-chart import reviews now persist and remain discoverable after restart.

The plugin update asks web versus desktop and adapts workflows to the connected library and actual capabilities. Plugin source/package availability, installation, sharing and public site deployment require separate verified release receipts. No production URL or changed installer pin is implied by this candidate.

Validation and remaining limits are recorded in docs/BROWSER-FIRST-IMPLEMENTATION-STATUS.md. Public deployment, release publication and plugin account updates are not performed merely by building this candidate. The previously documented Mac DMG build dependency advisories remain tracked separately.
