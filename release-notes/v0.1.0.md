# ORNL OrgChart Studio 0.1.0

This first command-line desktop test release provides private local chart storage, reviewed AI-assisted edits and imports, manual layout tools, accessible table views, backup and restore, version history, and presentation exports.

## Installation

- Apple Silicon macOS: use the public Terminal commands in the desktop quick-start PDF.
- Windows x64: use the public non-administrator PowerShell commands in the same guide.

No GitHub login, Apple developer account, Microsoft signing account, or signed installer is required. Repeating the same commands updates or repairs the local application copy while preserving chart data stored separately in Application Support or AppData.

The application does not include chart databases, retained source documents, or user backups. Those remain in folders chosen on each computer.
