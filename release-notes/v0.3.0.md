# OrgChart Studio 0.3.0

Support panels preserve matrix support, shared-service and advisory assignments independently of organizational units and supervisory lines. Each assignment retains role, person, status, visibility and source evidence. Source geometry captures card sizes/positions, support-panel placement and connector paths. Opening a chart with a captured arrangement defaults to that saved source arrangement; compact presentations remain explicit alternatives.

Structured AI and human source comparisons retain dates, evidence, scope and findings. A content fingerprint identifies checks made stale by changed facts. AI comparisons do not clear human-review flags or designate Current. MCP adds get_source_checks and record_source_check; the latter can create AI records only.

Support content and geometry survive named versions, historical checkpoints, monthly updates and schema-v6 full backups. Older schemas 1–5 remain supported; older clients cannot silently erase support panels. Internal/public diagram and accessible CSV exports account for support assignments, and names remain excluded from public exports. Canonical JSON imports support the new layout and panels; full backups transport comparison history.

No migration invents source coordinates or changes existing charts. Source arrangement must be captured from the actual source and reviewed. Existing records, layout and approval history remain intact.
