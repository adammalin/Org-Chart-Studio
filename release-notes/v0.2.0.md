# OrgChart Studio 0.2.0 — local monthly workflow candidate

This is an unsigned/ad-hoc-signed local test candidate, not an institutional production approval.

- Added per-launch isolated runtime builds so rebuilding development files cannot alter an open workspace.
- Added bounded local-service recovery, a recovery screen, local diagnostics without tokens or chart content, and a private editor recovery copy.
- Added cross-chart assignment, role and reporting comparisons; planned records and ambiguous repeated identities remain explicit.
- Added a prioritized review workspace with source evidence and categorized questions.
- Added monthly progress, explicit chart scope, reviewed batch decisions, resumption, Current designation and final checkpoints. Groups of up to ten reviewed decisions commit atomically with history and receipts.
- Added source-linked dated role and change questions with missing-coverage reporting. No earlier assignments or effective dates are inferred.
- Added three scoped MCP insight tools and an isolated native monthly/recovery/export/import journey shared by macOS and Windows CI.
- Retained unencrypted-by-default v5 exports, optional encryption, history-preserving merge imports, source controls, and rollback checkpoints.

Qualification must record actual platform results. A macOS run does not qualify Windows; Windows execution remains pending until its native CI job runs.
